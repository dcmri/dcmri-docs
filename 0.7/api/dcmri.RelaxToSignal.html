dcmri.RelaxToSignal#

class RelaxToSignal(imap=None, omap=None, iomap=None, cmap=None, **config)[source]#

Bases: Module

Compute the MR signal from tissue relaxation rates.

Chains two modules: Magnetization, which computes the magnetization time course M for a given acquisition sequence, and Signal, which converts M into the measured signal S (magnitude and noise, triggering, calibration). The configurations of both modules are combined. M and tM are produced by the first stage and consumed by the second, so they are outputs of this module and not inputs.

The tables below list all configurations, inputs and outputs. Which of them are active depends on the configuration. To list the ones that apply to a given instance, use its inputs() and outputs() methods.

Parameters:

  • imap (dict, optional) – Optional mappings for input, output, input and output, and configuration names (see Module).

  • omap (dict, optional) – Optional mappings for input, output, input and output, and configuration names (see Module).

  • iomap (dict, optional) – Optional mappings for input, output, input and output, and configuration names (see Module).

  • cmap (dict, optional) – Optional mappings for input, output, input and output, and configuration names (see Module).

  • **config – Configuration options as listed under Configurations, for example sequence='2D-SPGR' or calibrate=True. Options that are not specified take their default value.
